# 接入钉钉机器人（群里 @ 它下指令）

接好之后，你可以在钉钉里直接和公司对话：

- 在群里 @ 机器人，或单聊机器人，下达目标、查进度、审批。
- 需要你决策的事，会推送到你和机器人的单聊里，直接回复指令就能处理。

使用钉钉 **Stream 模式**：由我们的服务主动连接钉钉，**不需要公网地址**，在自己电脑上运行也能用。

> 这和「规则 → 消息推送」里的 Webhook 群机器人不同：Webhook 机器人只能单向发消息，不能接收消息。两者可以同时使用。

## 一、在钉钉开放平台创建应用

需要钉钉企业的管理员或开发者权限。没有的话，可以自己创建一个测试企业。

1. 打开 [钉钉开放平台](https://open-dev.dingtalk.com/)，进入「应用开发 → 企业内部应用」，创建应用。
2. 在应用里**添加「机器人」能力**：
   - 填写机器人名称、简介；
   - **消息接收模式选「Stream 模式」**；
   - 保存后**发布**机器人。
3. 在「凭证与基础信息」里复制 **Client ID（AppKey）** 和 **Client Secret（AppSecret）**。
4. 在「权限管理」里确认已开通「企业内机器人发送消息」权限（`qyapi_robot_sendmsg`），推送单聊消息要用到。
5. 发布应用版本，可见范围至少包含你自己。

钉钉后台的界面经常调整，如果菜单名称对不上，以官方文档「Stream 模式接入机器人」为准。

## 二、配置 Agent Factory

在项目根目录的 `.env` 里填写（**不要把 Secret 发到聊天里或提交到 git**）：

```
DINGTALK_CLIENT_ID=你的 Client ID
DINGTALK_CLIENT_SECRET=你的 Client Secret
```

重启服务后，打开顶栏「规则 → 聊天机器人」，钉钉一项显示「已连接」就说明成功。如果显示「连接失败」，后面会附上原因，常见原因：

| 提示 | 原因 |
|---|---|
| 凭证无效 | Client ID 或 Secret 填错，或者应用没有发布 |
| 一直在「连接中」 | 机器人没选 Stream 模式，或者没有发布 |

## 三、设置管理员

只有管理员能派活、审批、暂停；其他人只能查状态。

1. 在钉钉里找到机器人（单聊，或者把它拉进群后 @ 它），发「**我是谁**」。机器人会回复你的 userId。
2. 把 userId 填到「规则 → 聊天机器人 → 管理员 userId」里，保存。可以填多个。
3. 点「发送测试消息」。你的钉钉单聊里收到测试消息，就说明推送通了。

> 单聊推送要求你在机器人的可见范围内。如果收不到，先给机器人发一条消息试试。

## 四、指令

在群里需要先 @ 机器人；单聊直接发送即可。

| 指令 | 作用 | 谁能用 |
|---|---|---|
| `帮助` | 查看指令列表 | 所有人 |
| `我是谁` | 查看自己的 userId | 所有人 |
| `状态` | 每个员工在做什么、进行中的目标、今日花费 | 所有人 |
| `待办` | 等你处理的事项 | 所有人 |
| `详情 编号` | 查看某件待办的完整内容 | 所有人 |
| `成本` | 今日和累计花费、预算 | 所有人 |
| `目标 P1 标题`（换行后可写详细说明） | 下达新目标，不写优先级默认 P2 | 管理员 |
| `批准 编号 备注` / `驳回 编号 原因` | 处理待办 | 管理员 |
| `告诉 员工名 内容` | 给某个员工插话，例如「告诉 老周 先做 P0」 | 管理员 |
| `暂停` / `复工` | 全公司暂停或恢复 | 管理员 |

关于编号：

- 可以省略 `A-` 前缀，例如 `批准 h3qwvw`。
- **只有普通操作审批**在只剩一件待办时可以省略编号。交付验收、请示、预算告警和 R2 高风险操作必须写明编号，防止误批。

推送给你的消息里会附上可以直接回复的指令，例如「回复『批准 A-xxxx 备注』」。

## 五、本地调试（不连钉钉）

启动服务时加上 `IM_SIMULATE=1`，就可以用接口模拟聊天：

```bash
curl -XPOST localhost:8787/api/im/simulate -H 'content-type: application/json' -d '{"text":"状态","userId":"你的userId"}'
```

## 已知限制

- 推送消息里还不能点按钮审批。要用按钮，需要在钉钉卡片平台创建互动卡片模板并处理卡片回调，留到下一步。
- 机器人只认文字消息，图片、语音会提示「暂时只支持文字指令」。
- `告诉` 只是把话转给员工，员工的回复目前在 Agent Factory 的日志里看，不会自动回到钉钉。
