# 员工模型

把模型文件放在这个目录，在公司配置（`company/profiles/*.json`）里加上 `avatar` 字段即可，所有员工共用一个模型，项圈颜色按岗位自动区分。不配置时使用内置的程序化奶蛙；模型加载失败也会自动退回奶蛙。

```json
"avatar": {
  "url": "/models/naiwa.glb",
  "height": 1.25,
  "rotationY": 0,
  "collarMaterial": "collar|项圈",
  "clips": { "type": "Typing", "walk": "Walk_Cycle" }
}
```

| 字段 | 说明 |
|---|---|
| `url` | 本目录下的文件，用 `/models/文件名` 访问 |
| `height` | 站立身高（米），模型会自动缩放到这个高度，导出单位无所谓。默认 1.25 |
| `scale` | 直接指定缩放倍数（写了就不按 height 算） |
| `rotationY` | 绕竖直轴旋转（弧度）。员工坐在工位时面朝 **-Z**，模型正面方向不对时用它校正，常见值 `3.1416` |
| `collarMaterial` | 项圈的材质名（正则），默认匹配 `collar` 或 `项圈` |
| `sitLift` | 模型没有坐姿动画时，坐下时抬高多少米，默认 0.4 |
| `clips` | 动作 → 动画名。不写时按动画名里的关键词自动匹配（见下表） |

## 导出要求

- **格式**：首选 **GLB**（glTF 二进制，可同时带贴图和骨骼动画）；也支持 `.gltf`、`.fbx`、`.obj`。OBJ 没有动画，只能整体移动和轻微起伏。
- **原点在脚底中心**最好（程序也会按包围盒自动把模型放到地面、水平居中）。
- （可选）想按岗位区分颜色时，把那个部位单独做成一个材质，材质名叫 `Collar`（或包含“项圈”），程序会按岗位改颜色；没有就不改。
- **不要用 Draco/Meshopt 压缩**（暂不支持），贴图用 PNG/JPG 即可。
- 一个文件里放全部动画，动画名包含下面的关键词就能被自动识别：

| 动作 | 用在什么时候 | 自动匹配的关键词 |
|---|---|---|
| idle | 站着（茶水间、站着谈话） | idle / stand / 待机 |
| walk | 走路 | walk / run / 走 |
| sit | 坐着（开会、工位上没事时的兜底） | sit / seat / 坐 |
| type | 工位上写代码、敲命令 | typ / keyboard / 打字 |
| mouse | 工位上操作浏览器 | mouse / 鼠标 |
| think | 思考（推荐：托下巴、抬头） | think / ponder / 思考 |
| talk | 说话（开会发言、当面请示） | talk / speak / 说话 |
| phone | 工位上空闲刷手机 | phone / 手机 |
| drink | 喝咖啡（工位空闲、茶水间） | drink / coffee / 喝 |
| wait | 等审批时张望 | wait / look / 张望 |
| sleep | 被暂停时打盹 | sleep / doze / 睡 |

## 动画不全也没关系

模型带**人形骨骼**（例如 Tripo、Mixamo 导出的，骨骼名形如 `L_Thigh / L_Calf / Spine01 / Head / L_Upperarm / L_Forearm` 或 `LeftUpLeg / LeftArm …`）时：

- 有对应动画的动作直接播放动画（例如只带了 walk，走路就用它）；
- 其余动作（坐下、打字、用鼠标、托下巴、刷手机、喝咖啡、张望、打盹、站着说话）由程序直接驱动骨骼摆姿势；
- 模型正面朝向会根据骨骼自动判断，一般不需要配 `rotationY`。

没有骨骼的模型（例如 OBJ）只能整体移动，坐下时按 `sitLift` 抬高。

如果自己做动画，坐姿类动画请在模型原点处“坐”（脚底在地面、臀部大约离地 0.5 米），这样正好坐在椅子上。

## 体积

模型会在打开页面时下载，建议把贴图压到 1024–2048 像素、整个文件控制在 10MB 以内，加载会快很多。
